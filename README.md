# Bluestock Fintech — Mutual Fund Analytics

## Project Overview

This project analyzes mutual fund industry, fund performance, investor transactions,
SIP activity, portfolio risk, and market trends.

The project was completed as part of the Bluestock Fintech Mutual Fund Analytics
internship.

The analysis combines Python, Pandas, NumPy, Matplotlib, SQL, SQLite, and Power BI
to transform raw datasets into cleaned analytical datasets, risk metrics,
recommendations, visualizations, and dashboards.

---

## Objectives

- Analyze mutual fund industry AUM and growth.
- Study fund performance and risk metrics.
- Analyze investor demographics and transaction behavior.
- Analyze SIP inflows and investor continuity.
- Calculate Value at Risk (VaR) and Conditional VaR (CVaR).
- Calculate rolling Sharpe ratios.
- Perform investor cohort analysis.
- Analyze portfolio sector concentration using HHI.
- Build a simple risk-based fund recommendation model.
- Develop Power BI dashboards for business insights.
